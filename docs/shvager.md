Своя гра (aka "Швагер", "свояк") - another type of intellectual game, similar in some aspects to "What?Where?When?". 
A game of Shvager consists of a set of themes. Each theme consists of 5 questions. These questions have a common "theme" in common. The questions have different value - from 10 to 50 points - depending on complexity. 

Each question has :
* a value (from 10 to 50)
* a text
* answer
* optional "zalik" - a list of alternative answers, which are accepted as correct.
* optional unaccepted answers - a list of answers, which are explicitly not accepted as correct.
* optional "form" - a specification of the form of the answer (for example, "таку назву", "слово із трьома однаковими голосними", "пристрій двома словами, одне з яких - прізвище" і т.д.)
* optional comment 
* optional source or sources - a list of links, books references, cites, etc which confirm facts in teh question or a comment.
* optional author

Each theme has:
* A title
* an author (one or many) - optionally
* a preamble. It can be a description of the theme, or a comment for players, which should be read before playing the theme.
* 5 questions of 10, 20, 30, 40 and 50 values in this order. Instead of a number/index, one uses the value of the question.

A package is a set of themes. A game of Shvager consists of one package. A package can have any number of themes, but usually it has 6-8 themes. A package has:
* a title
* an author (one or many) - optionally
* a preamble. It can be a description of the package, the list of testers, or a comment for players, which should be read before playing the package. Often it conatains the fuyll list of themes in the package - titles only.


The rules of the game is the following:
* The game is played by 3-4 players. Each player has a score, which is 0 at the beginning of the game. 
* The game is played theme by theme. The themes are played in the order they are listed in the package
* Each theme consists of 5 questions. The questions are played in the order of their value - from 10 to 50.
* A value is announced. The question is read. The player who presses a button first gets the right to answer. If the answer is correct, the player gets the value of the question added to his score. If the answer is incorrect, the value of the question is subtracted from his score, and the other players get a chance to answer (who presses button the next). If no one answers correctly, the question is closed and the game moves to the next question.
* After all 5 questions of the theme are played, the game moves to the next theme. After all themes are played, the game ends and the player with the highest score wins.
